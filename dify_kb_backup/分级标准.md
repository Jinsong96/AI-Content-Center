分级标准：A1.1 – B2+.3（教研内容生产用 · 12 子档）

用途：作为 Dify 知识库「KB1-分级标准」的导入语料。工作流中的「分级」节点按本表判定素材适合的档位并给出理由；「生成」节点按本表的词数 / 蓝思 / 句长 / 体裁配比 / 题目分布逐档产出。

版本：2026-09-10 起为唯一有效版本，取代旧的 A2 / B1 / B2 三档标准。旧标准全部作废。

================================================================
一、总体原则
================================================================

1. 以欧盟语言共同参考框架（CEFR）为基准，面向中文母语学习者。
2. 分 4 个大档、12 个子档：A1（A1.1/A1.2/A1.3）· A2（A2.1/A2.2/A2.3）· B1（B1.1/B1.2/B1.3）· B2+（B2+.1/B2+.2/B2+.3）。
3. 12 个子档之间是「同一主题、12 种深度与语言复杂度」，不是 12 个割裂的选题。同一素材可按需生成其中任意档位。
4. 每个子档由 7 个可量化维度共同定义，判定时必须综合看，不允许只看词数：
   - 词数区间
   - 蓝思（Lexile）区间
   - 平均句长
   - 主题范围（读者需要的生活 / 认知经验半径）
   - 语言难度（新增时态、从句、语态、词汇层级）
   - 体裁配比（记叙 / 说明 / 应用文 / 议论）
   - 题目分布（语言 / 文本 / 逻辑 / 认知 四类题数）
5. 唯一命名格式为 `A1.1` 形式（点号分隔），不要写成 `A1-1` 或 `A1.1档`。

================================================================
二、题目四分类的定义（12 档通用）
================================================================

- 语言题：考词汇与语法本身。词义辨认、指代、上下文猜词。
- 文本题：考文中信息。细节定位、顺序、主旨、跨段落信息整合。
- 逻辑题：考推理与论证结构。单步因果、一步推断、论点与支撑的区分。
- 认知题：考立场与隐含前提。作者态度、各方立场归位、隐含假设。认知题不考「文章讲了什么」。

题目总数固定每档 3 题。各档只改变四类题的比例，不改变题量。

================================================================
三、A1 档（入门 · 全新档位）
================================================================

────────────────────────────────
A1.1｜60–90 词｜蓝思 BR–200L
────────────────────────────────
主题：读者五米之内的世界——家人、宠物、一顿饭、天气、上学路上。一个场景一件事，不设转折。
语言难度：一般现在时、be 动词、there be。连接词只用 and / but。
平均句长：5–7 词。
体裁：100% 记叙。
题目分布：语言 2 / 文本 1。全部答案在原文可见，读者只需回到文中指认。不出逻辑题。

────────────────────────────────
A1.2｜90–120 词｜蓝思 200–300L
────────────────────────────────
主题：动物、身体、四季、简单节日。故事出现「先……然后……」的两段式结构。
语言难度：新增现在进行时、can / like to、because / so。
平均句长：7–9 词。
体裁：仍为纯记叙。
题目分布：语言 1 / 文本 2。文本题里含一道顺序题，对应新出现的时间线。

────────────────────────────────
A1.3｜120–160 词｜蓝思 300–400L
────────────────────────────────
主题：从「我每天做什么」转向「我昨天遇到了什么」——第一次读到有事件、有变化的文本。出现极简说明文（一图配五六句话讲一个事实）。
语言难度：一般过去时（规则动词 + 约 20 个高频不规则）。
平均句长：8–10 词。
体裁：记叙 90%、说明 10%。
题目分布：语言 1 / 文本 1 / 逻辑 1。逻辑题只做单步因果，且原文有 because 之类的显性标记。

================================================================
四、A2 档（初级）
================================================================

────────────────────────────────
A2.1｜160–200 词｜蓝思 400–500L
────────────────────────────────
主题：兴趣爱好、旅行出行、购物、朋友与情绪、运动。文章开始有开头—发展—结尾，或总分关系。
语言难度：新增比较级、be going to / will、基础定语从句（who / which）。
平均句长：10–12 词。
体裁：记叙 60%、说明 30%、应用文 10%（邮件、通知、日程、菜单）。
题目分布：语言 1 / 文本 2。文本题首次出现主旨题，但中心句在原文里明写。

────────────────────────────────
A2.2｜200–250 词｜蓝思 500–580L
────────────────────────────────
主题：具象科普进场——动物为什么冬眠、雨是怎么来的、人为什么打哈欠。商业类首次出现，形式是「一个人做一件小生意」的故事而非概念。
语言难度：新增现在完成时、情态动词、when / if 状语从句。
平均句长：11–13 词。
体裁：记叙 50%、说明 40%、应用文 10%。
题目分布：语言 1 / 文本 1 / 逻辑 1。语言题从词义辨认转向指代。

────────────────────────────────
A2.3｜250–300 词｜蓝思 580–650L
────────────────────────────────
主题：第一次离开读者的直接生活经验——别的国家的人怎么生活、一百年前的人怎么出行、简单的中外对比。真正的门槛不在语言，在读者要开始想象没见过的东西。
语言难度：新增初步被动语态、过去进行时。
平均句长：12–14 词。
体裁：记叙 45%、说明 45%、应用文 10%。
题目分布：语言 1 / 文本 1 / 逻辑 1。逻辑题首次要求一步推断——答案不在原文字面上。

================================================================
五、B1 档（中级）
================================================================

────────────────────────────────
B1.1｜300–380 词｜蓝思 650–720L
────────────────────────────────
主题：科技产品、环境与可持续、学习方法与心理学、求职与办公入门。阅读目的从「练英文」转向「知道点什么」，读完应能复述给别人听。
语言难度：新增被动语态、宾语从句、动名词与不定式作主宾语。
平均句长：13–15 词。
体裁：说明 / 议论 55%、记叙 30%、应用文与说明文 15%。
题目分布：语言 1 / 文本 1 / 逻辑 1。语言题固定为上下文猜词，文本题的主旨不再明写。

────────────────────────────────
B1.2｜380–450 词｜蓝思 720–800L
────────────────────────────────
主题：社会现象、创业与商业常识、健康科学。文章首次出现明确的作者立场，不只是陈述事实。
语言难度：新增条件句 I / II、现在完成进行时、非限定性定语从句。
平均句长：15–17 词。
体裁：议论比重升至 25%。
题目分布：语言 1 / 逻辑 1 / 认知 1。认知题首次出现，问的是作者的态度，而不是文章讲了什么。

────────────────────────────────
B1.3｜450–550 词｜蓝思 800–880L
────────────────────────────────
主题：人物故事、事件复盘、深度一点的文化对比。这一级鼓励读完 500 词而不放弃，所以选题吸引力要压过语言难度。
语言难度：新增过去完成时、报道性动词（claim / argue / suggest）、分词短语作状语。
平均句长：16–18 词。
题目分布：文本 1 / 逻辑 1 / 认知 1。文本题转为跨段落信息整合；语言题退出——到这一级词汇障碍应由生词本和高亮承接，不占题目。

================================================================
六、B2+ 档（中高级 / 进阶）
================================================================

────────────────────────────────
B2+.1（B2）｜550–700 词｜蓝思 880–1000L
────────────────────────────────
主题：主流媒体的解释性报道与商业案例——AI 与就业、气候政策、公司兴衰、消费行为、健康科学。
语言难度：名词化密度上升、hedging（tends to / it is likely that）、倒装、多重从句嵌套。
平均句长：18–21 词。AWL 学术词密度 4–6%。
体裁：新闻特写与说明性长文为主，议论 30%。
题目分布：文本 1 / 逻辑 2。逻辑题转向论证结构本身——哪句是论点、哪句是支撑。

────────────────────────────────
B2+.2（B2 高 – C1 过渡）｜700–900 词｜蓝思 1000–1120L
────────────────────────────────
主题：有真实争议、有多方立场的议题——媒体信任、教育公平、算法伦理、老龄化与移民、全球供应链。
语言难度：出现反讽、隐喻、让步结构与显性的作者声音。
平均句长：20–23 词。AWL 密度 6–8%。
体裁：评论、书评、长篇特稿、研究综述科普版。
题目分布：逻辑 1 / 认知 2。认知题问的是隐含前提和各方立场的归位。

────────────────────────────────
B2+.3（C1）｜900–1200 词｜蓝思 1120–1300L
────────────────────────────────
主题：抽象论证、跨领域引用、文学性非虚构、当代思想散文、学术论文的引言与讨论部分。
语言难度：句法复杂度与词汇抽象度同时到顶。
平均句长：22–26 词。AWL 密度 8–10%。
体裁：抽象论证与文学性非虚构为主。
题目分布：逻辑 1 / 认知 2。到这一级没有标准答案式的正确项，选项之间是解读的优劣而非对错，解析比选项本身重要。
特别要求：难度有一半来自文化预设而非语言，因此每篇必须配「背景导读」——不是词汇注释，而是「你需要先知道什么背景才读得进去」。

八、常见误判（判定时必须避免）
================================================================

1. 只看词数定档 —— 蓝思、句长、题目认知层级必须同时达标，任一项显著超出即降档。
2. 把「生僻但短」当低档 —— 句短但概念抽象（如哲学比喻）不是 A1/A2，认知难度归入 B2+。
3. 跨档混用体裁 —— A1/A2 主体必须是记叙；让 A2.1 写议论文是硬错误。
4. 给 A1/A2 出逻辑题或认知题 —— A1.1 绝不出逻辑题；A1.2 及以下无逻辑题；认知题 B1.2 才首次出现。
5. 忘记 B2+.3 的背景导读 —— 该档缺导读视为不合格。

九、输出格式要求（分级节点）
================================================================

分级节点输出 JSON：

```json
{"level":"B1.1","reason":"主题适合中级学习者；词数 300–380、蓝思 650–720L、句长 13–15 词均达标","suggested_angle":"价格与电池技术驱动出海"}
```

- `level` 取值只能为：A1.1 / A1.2 / A1.3 / A2.1 / A2.2 / A2.3 / B1.1 / B1.2 / B1.3 / B2+.1 / B2+.2 / B2+.3。
- `reason` 控制在 40 字内，必须引用本表中至少两个量化维度作为依据。
