# 一鹿知 · 内容生产平台

> **本目录 = 仓库内的 `V3-Content-Factory/`。下文所有相对路径均相对本目录。**
> **给这个仓库的 AI 或人：先读 [`AGENTS.md`](AGENTS.md)，再读 [`docs/00-需求澄清实录-grill-me.md`](docs/00-需求澄清实录-grill-me.md)。**
> 这两份决定你会不会做错方向。本文只负责"这是什么、文件在哪"。

一个**分级阅读内容工厂**：输入一篇英文原文，输出四个难度的文章 + 一套题目 + 质检报告。

```
英文原文 (B2+) → ① 生成(GPT系) → ② 确定性脚本质检(15类) → ③ 异源语义裁判(DeepSeek系) → ④ 渲染(JSON+docx) → ⑤ 审校编辑
```

**全链路只有 2 次模型调用**，其余全是确定性 Python 代码。**零第三方依赖。**

## 跑起来

```bash
cd V3-Content-Factory
python3 app.py 8801     # 只用 Python 标准库，无需 pip install
# → http://127.0.0.1:8801
```

首次启动后自带一篇示例文章（`data/articles/seed-example-honesty/`），可以直接看到完整成品形态。
想重新导入：`python3 seed.py`。

### 配置模型

打开界面右上角「**模型设置**」，分别填生成模型与裁判模型（都走 OpenAI 兼容的 `/chat/completions`）：

| | 建议 | 示例 |
|---|---|---|
| 模型 A（生成） | 能力强的通用模型 | `https://api.openai.com/v1` + `gpt-4o` |
| 模型 B（裁判） | **与 A 不同来源**的推理模型 | `https://api.deepseek.com/v1` + `deepseek-reasoner` |

> **密钥只存在浏览器 localStorage，随请求体转发，不写服务器磁盘、不进代码仓库。**
> 也可改用环境变量服务端配置：`GEN_BASE_URL / GEN_API_KEY / GEN_MODEL`、`JUDGE_BASE_URL / JUDGE_API_KEY / JUDGE_MODEL`。

## 这个项目要证明什么

上一代（V1）搭了 8 个工作流，效果**不如**裸模型 + 老师 skill。
诊断：**8 次串联 = 8 次信息损耗 + 0 次质量增益**，而且**没有 evals**。

所以本项目的证明目标不是"展示编排"，而是**展示裸模型给不了的增量**：

- **稳（A）** = 15 类确定性脚本校验，不靠模型更聪明，靠脚本挡掉不合格
- **门槛低（C）** = 老师上传原文即得成稿 + 质检报告，不用写 prompt、不用装环境

**实测证据**：新增的「A1- 人名保留」规则当场抓出 `Franklin` 和 `Graves` 两个人名丢失 ——
而老师原脚本在同一篇文章上判定「✓ 通过」。**脚本过了 ≠ 内容对。**
