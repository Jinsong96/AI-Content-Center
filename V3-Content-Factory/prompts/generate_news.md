# 分级卡片生成（新闻原稿 → 四级）

我会发给你一篇英文**新闻原稿**。它的难度和篇幅都不固定 —— 可能比 B2+ 难，也可能偏长。
请你基于它写出四个级别的分级阅读材料：**A1-、A2、B1、B2+**，并为四个级别各出 3 道题。

- **B2+**：把新闻原稿**简化**到 B2+ 水平（高中生以上能读懂），保留全部核心事实与立场。
- **B1 / A2 / A1-**：在 B2+ 的基础上继续向下降级。
- 项目知识库里的 `example_honesty/cards.json` 是标准范例，格式和质量都以它为准。

## 输出要求
- 只输出一个 ```json 代码块，前后不写任何说明。不要调用工具，不要生成文件。
- **四个级别都必须写出完整正文** —— B2+ 也要你写出来，不是引用原稿。
- 在 `source_level` 里给出你对新闻原稿 CEFR 难度的估计（从 `A1-` / `A2` / `B1` / `B2` / `C1` / `C2` 里选一个）。
- 如果我说"重写 B1"或"修改 A2 Q2"，只输出那一部分的 JSON 片段。

## B2+ 怎么写（这一节最重要）
B2+ 是新闻原稿的**简化版**，既不是缩写、也不是脱离原稿重写：

- **必须保留**：全部核心事实、数字、时间、地点、引语要点；主体（谁对谁做了什么）；立场；确定性程度。
- **可以简化**：拆开超长句；把生僻词、行业术语、抽象表达换成常见说法；删掉与主线无关的次要铺垫、重复举例、背景赘述。
- **不得新增**原稿没有的事实、观点或数据。

篇幅目标 **300–600 词**：
- 原稿长于 600 词 → 删次要细节，压到 600 词以内。
- 原稿本就在 300–600 词之间 → 核心信息全保留，篇幅可与原稿相当。
- 原稿短于 300 词 → **不要为凑字数添加内容**。信息就这么多，按实际写，并在 `source_level` 里如实标注原稿偏简单。

## 切卡
- 先按 B2+ 的信息单元把 B2+ 切成 10 张卡（内容多时可以到 12 张）。直接引语不能跨卡。
- 四个级别卡片数相同，第 N 张卡在每一级讲的都是同一件事。

## 各级硬指标
| | A1- | A2 | B1 | B2+ |
|---|---|---|---|---|
| 词数占 B2+ | 30–42% | 48–60% | 65–78% | 基准（100%） |
| 单句词数 | 4–12 | 5–16 | 6–22 | 8–28 |
| 语法 | 一般现在/过去时、can、and/but/so/because/then；禁用从句、may/might/must、if、动名词作主语、被动 | 加上现在完成、will、should/must/have to、when/if/because 从句、who/that 短关系从句 | 加上 which/whose、第二类条件句、被动、间接引语、however/although | 常见语法结构不限，但仍须避开过度书面化的长难句与生僻结构 |
| 专有名词 | 全文最多 3 个 | 保留主要人名 | 全保留 | 全保留 |

## 保真（最重要）
- **基准是新闻原稿**（不是 B2+）。原稿的核心观点和事实在每一级都要保留。降级只能通过删细节、换词、拆句来实现。
- **删细节、换词，都不得删掉「定住词义」的语境。** 一词多义的实词（degree、class、term、mean、
  state、order 等）在低级别出现时，必须给出足以锁定义项的上下文 —— 以 degree 为例，要让它在这一级
  只能读成「学位」，读不成「温度/角度」。那一级承载不了这个语境，就换成一个没有歧义的等义说法，
  或者这一句不写。
- 不得新增原稿没有的事实。不得改变主体（谁对谁做了什么）。推测不能写成断言，反问不能写成肯定，作者的立场不能改。
- 从新闻标题和原稿核心中选 3–5 个主题词，写进 `topic_words`，每一级都必须出现，不得替换成同义的简单词。主题词第一次出现的那张卡，要给出足以推断词义的语境。
- 原稿中的习语，低级别改用直白的说法。

## 题目
- 每一级 3 道题，每题 4 个选项。只能依据本级的正文出题，答案必须能在本级正文里找到。
- 题型：A1-/A2 考语境词义和细节；B1 考细节、原因和作者态度；B2+ 考比喻义推断、段落关系和写作意图。
- 答案字母要分散。干扰项要合理，其中至少一个来自文中其他位置的信息。
- 解析固定两句：`卡片X说"<本级正文原句>"，……所以X正确。X最容易误选，因为……`。引用的英文必须和本级正文逐字一致。

## JSON 格式
```json
{
 "title_en": "", "title_zh": "",
 "source_level": "B2",
 "topic_words": ["", ""],
 "levels": {
  "B2+": {"cards": ["不带编号的卡片正文", "..."],
          "questions": [{"q": "", "options": ["", "", "", ""], "answer": "B", "explanation": ""}]},
  "B1":  {"cards": [], "questions": []},
  "A2":  {"cards": [], "questions": []},
  "A1-": {"cards": [], "questions": []}
 }
}
```
