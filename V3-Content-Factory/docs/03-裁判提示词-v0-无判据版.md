# 裁判提示词 v0 —— 无细判据版

> 用途：第二道关卡（异源模型裁判）的第一版提示词。
> 设计原则：**给它"为什么"，不给"什么算错"**。附知识（词表 / 语法清单），不附判定细则。
> 状态：草案。等真实试跑后按误报情况再决定是否升级到 v1（带细则）。

---

## 一、为什么是这一版形态

三句话：

1. **"没有判据"不存在。** 提示词里总要写东西，写了的都是判据。真正可选的是**粒度**。
2. **判据 vs 知识必须分开。** 口径问题（什么算"同一件事"）可以留给模型；事实问题（A1- 的词汇表）必须喂给它——否则它无从判起，只能瞎猜。
3. **误报的代价远大于漏报。** 误报会触发无谓重写，把本来合格的内容改坏。所以第一版的调性是"宁缺勿滥"。

---

## 二、提示词本体（可直接复制使用）

```text
你是一位资深的英语分级阅读教研，负责审核 AI 改写出来的分级阅读材料。

【背景】
- 你会看到同一篇英文文章的四个难度版本：A1-、A2、B1、B2+，以及每个级别的 3 道题。
- B2+ 是原文，A1- / A2 / B1 是从原文降级改写出来的。降级只能通过删细节、换词、拆句实现。
- 读者对象：A1- 给小学生，A2 给初中生，B1 给高中生，B2+ 给高中生以上。
- 读者是**连续阅读**的：他可能读完 A1- 的第 1 段，接着读 A2 的第 2 段，再读 B1 的第 3 段。
  系统会根据他的阅读感受动态调整下一段的难度。所以不同难度之间必须能接上。

【你的任务】
找出改写中的问题，重点看三类：

1. 内容不一致 —— 四个级别讲的不是同一件事；或跨级连续阅读时接不上。
2. 事实保真 —— 相比原文，新增了事实、删掉了核心事实、或改变了主体/立场/确定性程度
   （例如把"推测"写成了"断言"）。
3. 难度不符 —— 出现了明显超出该级别读者水平的词汇或句式。
   判断方式：**不要逐词核对词表**，而是站在"这个级别的学生读不读得懂"的角度看。
   只报**明显超纲**的（例如给小学生用了 unscrupulous 这类词），边缘情况不要报。
   **主题词和专有名词即使看起来偏难，也一律不算超纲**，不得报为问题。

【重要要求】
- **宁可漏报，不要误报。** 只有你确定这是问题时才报。拿不准的不要报。
- 判断难词时不要逐词核对词表，凭"该级别学生是否读得懂"判断；只报明显超纲的。
- **主题词（如 honesty）和专有名词（人名、地名）不得报为超纲问题。**
- 不要为了显得认真而凑数。没有问题时直接说"未发现问题"，这是可以接受的结论。
- 每报一条，必须包含：
  - 级别（A1- / A2 / B1 / B2+）
  - 位置（第几张卡；如果是题目，第几题）
  - 问题类型
  - 具体的句子：原文怎么写、改写怎么写
  - 一句话说明为什么这是问题
- 不要提出改写建议，只负责指出问题。

【输出格式】
只输出一个 JSON 代码块，不要任何其他文字：

{
  "findings": [
    {
      "level": "A1-",
      "location": "卡6",
      "type": "fact_altered",
      "original": "原文的原句",
      "rewritten": "改写的句子",
      "why": "为什么这是问题"
    }
  ],
  "conclusion": "未发现问题 或 共发现 N 处问题"
}
```

**注意**：上面这份提示词里，**没有任何一条"什么算错"的细则**。它只给了目标（读者是谁、怎么读、要保住什么），把判断权交给模型。这是 v0 的核心特征。

## 三、v0 故意不包含什么（以及为什么）

| 没给什么 | 为什么暂时不给 |
|---|---|
| 8 类问题的边界细则（什么算 `card_misaligned`） | 现在定 = 拍脑袋。等看过真实误报再定才有依据。 |
| P0 / P1 严重度分级 | 模型不知道你们的业务优先级。先让它**报问题**，严重度由人来定。 |
| 具体的词表 | 词表是"累计列表"，只能判"在不在表里"，判不了"这个词在这个语境里能不能猜出来"，还容易和"主题词必须保留"打架。**先让模型凭读者水平判断**，只报明显超纲的。 |
| 修改建议 | 会诱导模型为了"给出建议"而虚构问题。先只报问题。 |

**特别说明「超纲」为什么不用词表**（Bryan 2026-09-28 决定，我同意）：

1. 词表是**累计列表**，只能判"在不在表里"，判不了"**这个词在这个语境里能不能被猜出来**"。
   而老师的方法论恰恰要求"主题词首次出现要给足可推断词义的语境"——这是词表表达不了的。
2. **词表会跟硬要求打架**：主题词（honesty 这类）本身就可能偏难，但必须保留。
   若给词表，系统会把它判成超纲 → 触发重写把主题词改掉 → 正好违反"A1- 不得因语料没有就丢掉主题词"。
3. **真正的风险不是个别难词，是整体复杂度失控** —— 而后者已经被脚本管住了（词数占比、句长上下限、语法信号词）。
4. **模型有实证能力**：核对 example_honesty 时发现，A1- / A2 / B1 **三级都把 `unscrupulous` 简化成了 `cheat`**
   —— 没有任何提示，模型自己就知道这个词太难。这说明"凭读者水平判断"是可行的。

**因此 v0 判难度，但不给词表；只报明显超纲；且主题词与专有名词豁免。**
若试跑发现判得太松（该报的没报），再上词表——**先看结果再决定**，与整体思路一致。

## 四、怎么验证它（跑之前先把尺子定好）

**三篇样本，两个数。**

| 样本 | 用途 | 看什么 |
|---|---|---|
| ① 已知有问题的文章 | 测**漏报** | 老师示例（`example_honesty`）本身就是——它含至少两处真问题（见下） |
| ② 你认为已经很好的文章 | 测**误报** | 裁判会不会无中生有 |
| ③ 难度偏难 / 偏简单的样本 | 测难度判断 | 但 v0 不判超纲，只看它有没有乱报 |

**老师示例里已知的两处真问题（用来测漏报，不用告诉裁判）：**

1. **事实被改动** —— 原文 `we have a greater chance of surviving`（存活概率更大）
   → A1- 卡⑥ 写成 `So they live longer`（**活得更久**）。**存活概率 ≠ 寿命。**
2. **跨级接不上** —— 原文 / A2 / B1 里的人名 `Benjamin Franklin`、`Philip Graves`，
   在 A1- 里被泛化成 `A man` / `A scientist`。
   读者从 B1 卡② 降到 A1- 卡② 时，接不上"这个人是谁"。

→ **这两个数就是 v0 的成绩单**：它抓到几个？有没有编出不存在的问题？

**重要提醒**：这一步的裁判必须用**真实模型**（DeepSeek 推理模型）跑，而且要有**人工标注的答案**做对照。
不能拿"看起来挺专业"当通过标准——那正是 V1 的病根（8 个工作流看着完整，但没人知道准不准）。

## 五、裁判与自动重写的关系（v0 的关键决策）

**v0 不直接触发自动重写。**

```
裁判报出问题  →  展示给人看  →  人点"重写这张卡"  →  只重写那一张
                                        ↓
                              （人判断裁判报得对不对）
```

**为什么**：如果裁判误报 → 自动重写 → 把合格内容改坏，**而且你还不知道是裁判错了**。
让人在中转一手，误报的代价就从"内容被改坏"降到"多显示一条提示"。

**什么时候可以开自动**：积累几十次真实使用，确认"裁判报的基本都该改"（误报率足够低）之后。
**这与"老师手改后重跑质检要给按钮"是同一条逻辑** —— 凡是可能误判的环节，先让人确认。

## 六、升级路径（如果 v0 不够用）

按顺序，**一次只加一种**，加完就测误报率：

1. **v0.1** —— 若漏报严重 → 加"事实逐条比对"的**操作要求**（要求它列出原文的每一条事实、再逐一检查），
   但仍然不给"什么算错"的细则。这是流程约束，不是判据。
2. **v0.2** —— 若误报严重 → 收紧"报告门槛"，明确要求它给出**原文与改写的双向引用**（拿不出来的不许报）。
3. **v0.3** —— 若某类问题系统性漏判 → **只给这一类**的细则，其余保持开放。
4. **v1.0** —— 上述都收敛后，再补 P0/P1 分级与自动重写。

**不要一次性把 8 类细则全写进去。** 那是 V1 的老路：先堆规则，再发现规则互相打架。
