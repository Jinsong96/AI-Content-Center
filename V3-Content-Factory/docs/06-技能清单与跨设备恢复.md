# 技能清单与跨设备恢复

> **为什么要存这份**：技能装在 `~/.workbuddy/skills/`，是**单台机器的本地目录**
> （已实测：该目录**不是 git 仓库、没有任何备份机制**）。
> 换电脑 → 技能不会跟过去。这份文档放在 iCloud 库（跨 3 台设备同步），新设备上让助手读它就能装回来。

## 结论先行

| 场景 | 技能会怎样 |
|---|---|
| **同一台电脑，换 WorkBuddy 账号** | ✅ 不用做任何事。`~/.workbuddy/skills/` 是**跨账号共享**的 |
| **换电脑** | ⚠️ **7 个自建技能会永久丢失**（无上游来源，只能靠本地文件备份）；市场上装的可按名字重装 |

**所以真正要解决的不是"装什么"，是第二节那 7 个。**

## 二、⚠️ 待决：这 7 个自建技能怎么备份

**它们没有上游仓库，本机文件是唯一副本。** 两个方案：

| 方案 | 做法 | 优点 | 缺点 |
|---|---|---|---|
| **A · 镜像进库** | 在库根下建 `_技能镜像/`，把 7 个目录整体拷进去 | 跟着 iCloud 走，零额外配置 | 会在 Obsidian 里多出 7 个文件夹、干扰笔记视图 |
| **B · 建私有 git 仓库** | 建一个私有 repo（如 `wb-skills`）存这 7 个，本机加软链或定期同步 | 有版本历史、干净、可协作 | 要手动 push |

**我的建议：B。** 理由：Obsidian 库是用来读笔记的，塞代码进去会破坏「打开就能写字」这个体验；
而且这 7 个技能里有脚本，本来就该进 git 而不是笔记库。**方案 A 只在不想再注册仓库时用。**

> ⚠️ 无论哪个方案：**库通过 iCloud + Apple 云端同步**，按 [[INDEX]] 的隐私边界，
> 技能里**不能含任何密钥**。备份前需逐个扫一遍。

## 三、`grill-with-docs` 三件套（当前**未装**，按需装）

**为什么单独记**：它做的是「追问的同时把结论写进 `CONTEXT.md` 和 ADR」，**问完不会聊完就散**。
对 ReadPal 这种已经有 `AGENTS.md` 约定的项目，比 `grill-me` 更合适。

**推荐市场里没有它**，只能从上游装。上游作者是 Matt Pocock：

```
仓库：https://github.com/mattpocock/skills
```

### 关键：它是「转发壳」，必须三件一起装

`grill-with-docs` 的正文只有一句：「调用 `grilling` 和 `domain-modeling`」。
**只装它一个 = 装了个死指针。**

| 技能 | 上游路径 | 作用 |
|---|---|---|
| `grill-with-docs` | `skills/engineering/grill-with-docs/SKILL.md` | 壳，247 字节，转发到下面两个 |
| `grilling` | `skills/productivity/grilling/SKILL.md` | **追问的引擎**：把决策画成设计树，按「前沿」分轮提问，每题给推荐答案 |
| `domain-modeling` | `skills/engineering/domain-modeling/`（3 个文件） | 术语表 + ADR 的落地纪律 |

### 装法

```bash
S=~/.workbuddy/skills
B=https://raw.githubusercontent.com/mattpocock/skills/main/skills

mkdir -p "$S/grill-with-docs" "$S/grilling" "$S/domain-modeling"

curl -sL "$B/engineering/grill-with-docs/SKILL.md"       -o "$S/grill-with-docs/SKILL.md"
curl -sL "$B/productivity/grilling/SKILL.md"            -o "$S/grilling/SKILL.md"
curl -sL "$B/engineering/domain-modeling/SKILL.md"      -o "$S/domain-modeling/SKILL.md"
curl -sL "$B/engineering/domain-modeling/CONTEXT-FORMAT.md" -o "$S/domain-modeling/CONTEXT-FORMAT.md"
curl -sL "$B/engineering/domain-modeling/ADR-FORMAT.md"     -o "$S/domain-modeling/ADR-FORMAT.md"
```

> 装完跟我说一声，我会先做一次安全审计再确认可用（这不是走流程：**从外部仓库直接落盘的文件必须看一遍**。
> 本次已审过，5 个文件全是纯 Markdown，0 可执行内容、0 网络调用，风险等级 P2）。

**2026-09-28 的处置**：装好后按你的要求**移出**了技能目录（不是删除），位置：
`~/.workbuddy/_skills_removed_20260928/`。要恢复就整个移回 `~/.workbuddy/skills/`。
