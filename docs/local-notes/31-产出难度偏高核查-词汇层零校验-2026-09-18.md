# 31 · 「产出难度偏高」核查：真因是词汇层零校验（2026-09-18）

> ⚠️ **本文 §10 的「方案 A」已作废 —— 见 `32-产出难度治理方案-2026-09-18.md` §1。**
> 词汇校验**早已上线**（桥接层 `/api/vocab-check` + 前端 `vocabCheck()` + 自动重试），
> 本文只核了 Dify 图、漏查了桥接层与前端。§1–§9 的实测与结论仍然成立，
> 但「没有校验」应改读为「**校验在跑，却纠正不了**」。
>
> Bryan 反馈：生产出来的文章难度高了 2 个等级（A1-→B1、A2→B2、B1→C1），
> 并给出他的参考工具 `https://www.roadtogrammar.com/textanalysis/`。

## 一、先把 Bryan 的工具拆开（不猜，读它的源码）

页面加载 `mydb.js`（词表）+ `controller.js`（算法）。

**算法**（`controller.js`）：

```js
rating = l / i          // l = 每个词在「10000 高频词表」中的排名和；i = 有效词数
d = x / r               // 平均句长
s = o / x               // 平均词长
if (s > 5) rating += 100
if (s > 6) rating += 500
if (d > 19) rating += 500
```

**等级刻度**（顺序赋值，取最后一个命中项 → 实际是自下而上的链）：

| rating | 判定 |
|---|---|
| < 700 | A2 |
| 700–1299 | B1 |
| 1300–1799 | B2 |
| 1800–2399 | C1 |
| > 2400 | C2 |

⚠️ **这个工具没有 A1 档** —— 最低只能判 A2。页面文案也确认它比的是
「词在 1 万高频词列表中的位置」，口径是**词频**，不是 CEFR 教学分级。

## 二、Bryan 那句话为何是 B2（逐词拆解）

```
A famous skier ran in a long trail race. She was an Olympic champion. She finished the race very fast.
```

页面实测：`word complexity 1679` → **B2**。词级来源：

| 词 | 词表排名 |
|---|---|
| champion | **8685** |
| famous | 3798 |
| runners | 3413 |
| skill | 3165 |
| trail | 2549 |
| skier / olympic | **不在表内** |
| the / was / she / very | 1 / 9 / 28 / 103 |

→ **判 B2 完全来自低频词，与语法无关**（平均句长仅 7、平均词长 4，都没触发加分）。

## 三、片段 vs 全文：同一篇文章差两个档

| 输入 | complexity | 判定 |
|---|---|---|
| 上面 3 句（19 词） | 1679 | **B2** |
| 同篇 A1- 全文（190 词） | 606 | **A2** |

工具自身提示「超过 50 词更准」。**短片段会被少量低频词拉爆**，不能用作档位判据。

## 四、工具刻度校准（用教科书文本）

| 样本 | complexity | 工具判定 |
|---|---|---|
| 教科书 A1 级（71 词） | 413 | A2 |
| 教科书 A2 级（71 词） | 698 | A2 |
| 教科书 B1 级（78 词） | 1046 | B1 |

→ 证实「工具无 A1 档」。**同档对比**才有意义。

## 五、平台产出 vs 同档教科书（全文实测）

| 平台标注 | 产出 complexity | 同档教科书 | 差距 | 工具判定 |
|---|---|---|---|---|
| A1- | 606（190 词） | 413 | +47% | A2 |
| A2 | **976**（253 词） | 698 | **+40%** | **B1** |
| B1 | **1224**（372 词） | 1046 | **+17%** | B1 |
| B2+ | 1453（632 词） | — | — | B2 |

**结论：4 档普遍偏难，A2 最严重（接近 B1 的 1046）** —— 与 Bryan「A2 像 B1」的感受一致。
不是「高 2 级」，是「低档偏难约 1 档、越靠低档越明显」。

## 六、偏难来自词汇层（句法层反而是偏低的）

同一批产出，平台自己的质检数据：

| 档 | 平均句长实测 | 规格要求 | 蓝思估算 | 规格要求 |
|---|---|---|---|---|
| A1- | 7.6 | 7–9 ✓ | 71L | BR–400 ✓ |
| A2 | 8.4 | 10–13 ✗偏低 | 142L | 400–750 ✗偏低 |
| B1 | 10.3 | 14–17 ✗偏低 | 354L | 750–1050 ✗偏低 |
| B2+ | 17.6 | 18–24 ≈ | 795L | 1050–1350 ✗偏低 |

→ **句长与蓝思普遍偏低，只有词汇偏高** ⇒ 偏难这一项来自词汇。

## 七、根因：词汇约束只写在提示词里，质检零核查

**GEN 工作流 13 个节点**：`nodeStart / nodeClean / nodeStyle / nodeTitle / nodeGenA1 / nodeGenA2 /
nodeGenB1 / nodeGenB2p / nodeAgg / nodeQuiz / nodeValidate / nodeGistCheck / nodeEnd`

`nodeValidate`（⑦ 校验节点）的检查项 **9 项**：

| # | 检查项 |
|---|---|
| 1 | 长度校验 |
| 2 | 句长校验 |
| 3 | 蓝思校验 |
| 4 | 敏感排查 |
| 5 | 语法粗筛 |
| 6 | 事实一致性 |
| 7 | 语言纯净度 |
| 8 | 身份完整性 |
| 9 | 合规署名 |

**没有词汇校验** —— `nodeValidate` 代码里 `vocab` / `EVP` / `超纲` 出现次数均为 **0**。
`EVP` / `超纲` 只出现在 4 个生成节点的**提示词**里（A1- 要求「只用 EVP A1（约 600 词族）；
超纲词率 ≤1% 且全文 ≤3 个」）—— 纯靠 LLM 自觉，**无机器核查、无反馈闭环**。

## 八、硬证据：平台自己的校验器一跑就报超纲

`backend/evp_vocab_check.py`（9751 词的 EVP 分级表，阈值 A1 5% / A2 4% / B1 3% / B2 2%）
根本没接进 Dify 工作流。手工对同一批产出运行：

| 档 | 超纲率（不含豁免） | 超纲率（含 topic words 豁免） | 阈值 | 判定 |
|---|---|---|---|---|
| A1- | 17.55% | **14.92%** | 5% | FAIL（**3 倍**）|
| A2 | 11.90% | **9.02%** | 4% | FAIL（2.3 倍）|
| B1 | 5.64% | **5.64%** | 3% | FAIL（1.9 倍）|
| B2+ | 2.88% | **2.22%** | 2% | FAIL（1.1 倍）|

**四档全部超标，低档超得最狠** —— 与「越靠低档越偏难」完全吻合。

各档超纲词实例（已豁免 topic words）：
- A1-：`race`(A2) · `champion`(B1) · `ski`(B1) · `by`(A2) · `lake`(A2) · `far`(A2) · `away`(A2) · `should`(A2)
- A2：`ski`(B1) · `medal`(B2) · `rough`(B1) · `skill`(B1) · `professional`(B1) · `director`(B1)
- B1：`superior`(C1) · `trail`(B2) · `rocky`(C1) · `slippery`(C1) · `overall`(B2) · `state`(B2)
- B2+：`superior`(C1) · `participant`(C1) · `counterpart`(C1) · `drain`(C2) · `teamwork`(C1)

⚠️ 注意 A1- 的超纲词里有 `by` / `far` / `away` / `lake` / `should` 这类**基础词** ——
说明 `cap = EVP A1`（643 词族）这个上限极窄，要用它写完 190 词的成人新闻改写**几乎不可能**。
**「阈值 + 词表上限」这组参数本身也需要复核**（是不是该按 A1/A2 合并放宽）。

平台的 EVP 标注（与 roadtogrammar 口径不同，但都是平台自己的标准）：
`famous`=A1 · `sport`=A1 · `snow`=A1 · `race`=A2 · `runner`=A2 · `coach`=A2 ·
`champion`=**B1** · `skill`=**B1** · `ski`=**B1** · `athlete`=**B1** · `training`=**B1** ·
`trail`=**B2** · `medal`=**B2** · `skier`/`olympic`/`lodge`/`hiking`=**表外**

⇒ **A1- 文章里出现 B1/B2/表外词，是违反平台自己规格的**，只是没人检查。

## 九、顺带发现 `check_vocab` 的一个漏洞

`check_vocab()` 的 `over_rate = over_total / content_total`，而 **`content_total` 只统计命中词表的词**；
表外词只进 `unknown` 列表，**既不进分子也不进分母**。所以 `skier` / `olympic` / `lodge` 这类
表外词对超纲率的影响为 **0** —— 越生僻的词越逃过校验。

## 十、方案（待 Bryan 拍板）

**A. 把词汇校验接进质检（推荐，治症状、闭环）**
- 桥接层已有 `evp_vocab_check`，新增 `/api/vocab_check`，前端生成完成后补检并显示在质检面板
- 或在 GEN 后补一个 code 节点（⚠️ 9751 词表约 150KB，Dify code 节点放不下 → 更适合放桥接层）
- 同时修 §9 的漏洞：表外词应计入超纲

**B. 收紧生成提示词的选词约束（治本，但依赖 LLM 自觉）**
- 明确「禁用高于本档 EVP 等级的词，topic words 除外且 ≤3 个」
- 局限：素材本身决定概念（写越野滑雪名将就绕不开 ski/Olympic）

**C. 低档不给「认知门槛过高」的素材（产品层）**
- 与 `level_lo` 硬门是同一件事的两面：FACT 判 lo 高时，低档确实写不出干净的文章
- 但不应像现在这样「静默把档位条抹掉」，而应明说原因
