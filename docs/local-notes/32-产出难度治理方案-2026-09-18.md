## 二、真问题：校验在跑，但形同虚设

### 2.1 硬证据（前端同口径复算：含生词表豁免、含标题）

用 `collectGenForVocab()` 的同口径，把 4 篇真实产出喂给 `check_vocab_batch`：

| 素材 | A1- (阈值5%) | A2 (4%) | B1 (3%) | B2+ (2%) |
|---|---|---|---|---|
| 09-18 实跑 | **30.9%** ✗ | **16.6%** ✗ | 3.4% ✗ | 1.7% ✓ |
| 科学类 | **26.0%** ✗ | **18.5%** ✗ | **15.4%** ✗ | 2.7% ✗ |
| CGTN 商业 | **26.0%** ✗ | **25.9%** ✗ | 9.2% ✗ | 3.5% ✗ |
| NPR 体育 | **22.4%** ✗ | 9.1% ✗ | 3.6% ✗ | 2.5% ✗ |

**16 个样本，15 个 `exceed = true`** ⇒ `any_exceed` 恒为真 ⇒ 必然触发 2 次重试（每次约 77 秒）
⇒ 重试完仍然超标 ⇒ 放行。**每次生成白花约 150 秒。**

### 2.2 原因 1 · 重试是空转（前端）

`runGeneration()` 里 `wfInputs` 在**循环外**算一次（`index.html:2662`），
三次重试传的是**完全相同的入参** —— 只是让 LLM 重新掷了一次骰子，
**没有任何约束变化**。约束只写在提示词里（「超纲词率 ≤1%」），LLM 一直在忽略它。

### 2.3 原因 2 · 判据本身不可达 / 有三处口径 bug

**(a) 功能词被当内容词统计。**

| 词 | 词表标注 | 事实 |
|---|---|---|
| `by` `over` `around` `another` `several` | **A2** | 基础介词/限定词 |
| `air` `far` `away` `lake` `race` `should` | **A2** | 基础名词/副词/情态动词 |

A1 档的 cap 是 `≤A1` ⇒ 上面每一个都算「超纲」。
一篇 190 词的短文里塞十几二十个 `by / over / should`，超纲率就上去了 —— **这跟难度无关**。

**(b) cap 不可达。** 词表各等级词头数：A1 **643** / A2 1078 / B1 1881 / B2 2560 / C1 1505 / C2 2084。
累计 `≤A1` 仅 643、`≤A2` 共 1721。
**用 643 个词族写 190 词的成人新闻改写，物理上做不到。** 所以 A1 档 22–31% 的超纲率里，
相当一部分是尺子的问题，不是文章的问题。

**(c) 前端显示的上限与后端实际判的不一致。**

| 档 | 前端 `offCap()` 显示 | 后端 `VOCAB_THRESHOLD` 实际 | 一致？ |
|---|---|---|---|
| A1 | 1% | 5% | ✗ |
| A2 | 2% | 4% | ✗ |
| B1 | 3% | 3% | ✓ |
| B2+ | **5%** | **2%** | ✗（正好反了）|

老师在界面上看到「A1- 超纲词上限 1%」，机器实际按 5% 判；
界面写 B2+ 上限 5%，机器实际卡 2%。**这是和 `MIN_USABLE_TEXT` 同类的双真源问题。**

**(d) 表外词漏洞**（文档 31 §9 已记）：`content_total` 只统计命中词表的词，
`unknown` 只进列表不进分子分母 ⇒ `skier` / `olympic` / `lodge` 这类词对超纲率影响为 **0**，
**越生僻越逃过校验**。

## 三、方案（三层，按执行顺序）

### 第 1 层 · 先把尺子校准（不做这步，后面全是白改）

| # | 动作 | 说明 |
|---|---|---|
| 1.1 | **标定基线** | 拿**教研认可的合格范文**（每档 1 篇，共 4 篇）跑一遍，得到「合格文章的超纲率」= 基线，再据此定 cap 与阈值。**现在的 5/4/3/2% 没有任何依据，是拍的。** |
| 1.2 | **功能词退出统计** | 超纲率只统计**内容词**（实词）；介词/限定词/助动词/代词/连词等封闭类词一律不参与。这是最明显的口径 bug。 |
| 1.3 | **阈值单一真源** | 前端 `offCap()` 与后端 `VOCAB_THRESHOLD` 合并成一个来源（接口下发或常量同源）。同 `MIN_USABLE_TEXT` 的教训：**改一边必须改另一边**。 |
| 1.4 | **修表外词漏洞** | 表外词计入分母（或单列「表外率」），不再享受「零影响」。 |
| 1.5 | **复核 cap** | 若标定证明 A1 不可达，就把 A1 档的 cap 调成 `≤A2`（1721 词族），并在规格文档里同步改写。 |

### 第 2 层 · 让校验能纠正，而不只是报警（治本）

| # | 动作 | 说明 |
|---|---|---|
| 2.1 | **超纲词回灌** | 重试时把上一稿的超纲词清单传给生成：GEN 加可选入参 `avoid_words`（逗号串），提示词里拼成「以下词超出本档，必须替换：…」。**让 LLM 有具体的替换目标**，而不是重复同一句软约束。 |
| 2.2 | **每档附禁用清单** | 在 4 个生成节点的提示词里附「本档禁用词清单」（cap 之上的高频词 top N），比「请使用 A1 词汇」有效得多。 |
| 2.3 | 保留现有重试 | 机制不动，但必须**带着约束重跑**；重跑时把 `avoid_words` 塞进 `wfInputs`。 |

> ⚠️ 2.1 / 2.2 要动 **Dify GEN 图**（加入参 + 改 4 个提示词）→ 走 §四 的改图流程 + 发布。
> ⚠️ 改动前先做第 1 层，否则回灌的还是那把歪尺子量出来的词。

### 第 3 层 · 素材认知门槛（产品层兜底）

FACT 已经给出 `level_lo`。当素材概念本身就超 A1（例：越野滑雪奥运冠军），
A1 档**不该硬生成** —— 生成出来的必然是超纲的。

现状行为有两个问题：
1. **静默抹掉低档**：`bigBarHTML()` 里 `if(indexOf(big) < minIdx) return ''` 直接不渲染低档。
2. **弹的文案是假的**：`genLevelGate()` 说「将只生成更高档位」，
   实际 Dify 4 档并行全生成（`nodeGenA1/A2/B1/B2p` 恒执行）。

应改为：**明说原因**（「该素材概念超 A1 档，生成的文章必然超纲」）+ 给可选动作
（换素材 / 接受超纲 / 只生成某档）。

## 四、收尾 · 教学

- 跑完整链路后，先把 4 档产出 + 生词表丢给 `/api/vocab-check`（或在桥接层直接调
  `evp_vocab_check.check_vocab_batch`），看 `any_exceed`。
- `any_exceed = true` 时，界面上的「超纲词」列表就是**回灌用的 `avoid_words`**。
