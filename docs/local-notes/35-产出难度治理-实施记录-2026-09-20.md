# 35 · 产出难度治理 · 实施记录（2026-09-20）

> Bryan 的需求原话：**「让热点搜集过来的素材，生产的文章稳定且符合标准，不至于太难」**。
> 三个阀门经他拍板「①②③ 全做」，阈值「用范文实测值」。

---

## 一、诊断：难度在链路上是**开环**的

不是「没要求」，而是**要求没人管**。实地核出来的四件事：

| 环节 | 真实状态 |
|---|---|
| 档位约束 | 4 档提示词**都写了**完整难度约束（各 3.4–3.9k 字符，含词数/句长/蓝思/超纲率/EVP cap）。但 A1- 那条「超纲率 ≤1%、只用约 600 词族」**物理不可达** → LLM 判定这组数字是装饰，**整组约束一起被忽略** |
| 机器校验 | `nodeValidate` 9 项：长度/句长/蓝思/敏感/语法粗筛/事实/纯净度/身份/署名 —— **无词汇项** |
| 回灌 | 前端确实会在超纲时重试 2 次，但 `wfInputs` 在循环**外**算一次 → 三次重试入参一字未改，纯掷骰子，白花约 150 秒 |
| 阈值 | **三套数字且方向相反**：提示词与前端 `offCap()` 都是 1/2/3/**5%**（越高档越松），后端 `VOCAB_THRESHOLD` 是 5/4/3/**2%**（越高档越严）→ **LLM 在优化一个和校验器相反的目标** |

一句话：**「生成 → 校验」有，「校验结果回到生成」断了。**

## 二、三个阀门与对应改动

### ① 统一口径

- `backend/evp_vocab_check.py` → `VOCAB_THRESHOLD = {A1: 5%, A2: 8.1%, B1: 3.6%, B2: 1.6%}`
  （范文标定 P75；A1- 无范文沿用 5%，标注「未标定」）
- `frontend/index.html` `offCap()` 同步 —— 此前它与后端**恰好相反**
- GEN 图 4 档提示词（待发布）：`超纲词率 ≤1/2/3/5% 且全文 ≤3/6/12/25 个`
  → `超纲词率 ≤5/8.1/3.6/1.6%`
  （同时**去掉「全文 ≤N 个」** —— 绝对个数与百分比是两套判据，后端只按百分比判，
  留着会让模型去优化一个没人在查的指标）

### ② 装上回路（治本 —— 只有这步能让文章**真的变简单**）

**后端**（`backend/evp_vocab_check.py`）

- `check_vocab` 新增 `avoid_words` 字段，由 `pick_avoid_words()` 挑词
- 新增 `_FUNCTION_WORDS`（约 180 词）：**剔除功能词**。
  原因：EVP 把 `by`/`over`/`around`/`another`/`should`/`far`/`away` 标在 A2，
  它们在 A1- 档全部算「超纲」—— 但这类词是句子骨架，**LLM 无法「避免使用」**，
  塞进禁用清单只会让它写出不通顺的英文。
- 新增 `backend/vocab_baseline.json`（3384 词），由
  `calibration/build_vocab_baseline.py` 从 345 篇范文抽取。
  判据：**范文里用过的词 = 教研认可的词**，不该要求 LLM 规避。
  为什么必须加：**EVP 表缺漏严重** —— 实测 `become`/`depend`/`accord`/`amplify`/
  `planner`/`canopy`/`galaxy`/`utility` 的**词根都不在 9751 词表内**。
  这些词掉进 `unknown`（表外），若不加辨别地回灌，会产出
  「请避免使用 becoming」这种错误指令。
  比较时用**词根**查基线（基线存 `become`，unknown 存 `becoming`，不比词根会漏判）。

**前端**（`frontend/index.html`）

- `wfInputs` **挪进重试循环内**，并带上 `avoid_words`
- 新增 `collectAvoidWords(v)`：按档打包 `{A1:[…], A2:[…], B1:[…], B2:[…]}`，
  只收**超标档**（没超标的档不该被约束，否则会把合格的稿子改坏）
- 重试提示改为「本轮规避 N 个超纲词」—— 让用户看得出这次重试不是白跑

**GEN 图**（待发布）

- `nodeStart` 加 `avoid_words`（paragraph，非必填）
- `nodeClean` 解析成 `avoid_a1/a2/b1/b2` 四个字符串（空值给明确文案，不留断头句）
- 4 个生成节点在【词汇层】后插入【本轮禁用词】段，引用本档变量
- 工具：`tools/patch_gen_graph.py`（**幂等**，已验证重复跑全部跳过；坏 JSON 安全降级）

### ③ 守住素材门槛

- `genLevelGate()` 文案改真话。旧文案「该素材词汇难度较高，无法生成 A1-、A2 档文章，
  **将只生成更高档位**」是**假的** —— GEN 一次同时生成 4 档，前端只是把低于下界的档
  **隐藏**并自动切档。改为：「生成后不会展示，档位会自动切到 X」。

## 三、本轮**未**修的问题（判据层，已记录待办）

1. **EVP 表缺漏** —— `become`/`depend`/`accord` 等常见词根不在表内，它们掉进 `unknown`，
   **既不进分子也不进分母**（越生僻越逃过校验的反面：越常见越逃过）。
   影响：超纲率被系统性高估（分母偏小）。
2. **`lemmatize` 缺 `-er → -e` 规则** —— `larger` 还原不出 `large`（候选只试了 `larg`）。
3. **A1- 档真正的问题是 cap 而非阈值** —— `EVP A1` 只有 643 词族，连 `by`/`over`/`around`
   都超纲，物理上写不出 195 词成人新闻改写。
   → **要教研拍板**：是否把 A1- 的 cap 放宽到 `EVP A1–A2`（1721 词族）。

这三条都不是技术能单方面决定的（涉及教研口径），已单列。

## 四、上线顺序（**关键**）

**必须先改 Dify 图，再上前端。**

- Dify 加了入参但前端不传 → 入参为空 → 走默认文案 → **无害**
- 前端传了 Dify 未声明的入参 → 有报错风险

顺序：

```
1. dump 线上 GEN 草稿 → patch_gen_graph.py → push → publish
2. push 后端 + 前端到 GitHub（Railway 自动部署，~90s）
3. 端到端实跑：真实素材 × 4 档，对比改前的超纲率与重试行为
```

## 六、执行中发现并修掉的两处**回灌质量**问题（2026-09-20 补充）

回灌不是「把超纲词原样丢给 LLM」—— 第一版实现跑出来会给出**错误指令**，实测后修了两处。

### 问题 1：基线过滤形同虚设（`lemmatize` 与 EVP 词表耦合）

**现象**：`depending` / `findings` / `according` / `canopies` 这些词本该被范文基线豁免，
却出现在规避词清单里。

**根因**：`lemmatize()` 只在「还原结果**命中 EVP 词表**」时才返回词根。
而 `depend` / `canopy` / `accord` / `amplify` 这些词根**本身就不在 EVP 表内**（表覆盖不全），
于是 `lemmatize('depending')` 原样返回 `depending` → 拿它去比基线必然不命中。

**修法**：新增 `_stem_variants(w)` —— 只做形态剥离，**不要求命中任何词表**，
且候选词与基线词**双侧降词干**再比。

### 问题 2：基线不该是一份全局词表，必须**分档**

**现象**：`build_vocab_baseline.py` v1 把 345 篇范文的词合成一份（3384 词）。
那样 B2 范文里的难词（`habitat` / `evaporation` / `canopy`）会给 **A2 也豁免掉** → 回灌失效。

**修法**：输出 `levels: {A2:[...], B1:[...], B2:[...]}` 三份，
消费侧按**本档及更低档**做累积并集（`_BASELINE_SRC`）：

| 本档 | 用哪几档范文当基线 | 词数 |
|---|---|---|
| `A1-` | A2（**外推** —— 我们没有 A1- 范文）| 1738 |
| `A2` | A2 | 1738 |
| `B1` | A2 + B1 | 3100+ |
| `B2+` | A2 + B1 + B2 | 4935 |

### 问题 3（同批修）：`over` 词也要过基线过滤

**为什么**：`A1-` 的 cap 是 EVP A1（**仅 643 词族**），**比教研的 A2 范文还低** ——
于是 `top` / `win` / `fan` / `side` / `care` / `heavy` / `race` 这些基础词全被算成「超纲」。
要求 LLM 规避它们，只会写出别扭的英文，而范文里明明在用。

**判据**：基线（= 教研认可的用词）里的词，不要求 LLM 规避 —— 不管它来自 `over` 还是 `unknown`。

**效果**（NPR 体育素材 · A1- 档）：规避词 **19 → 11**，`top`/`win`/`fan`/`side`/`race`/`care`/`heavy` 已剔除，
留下的 `medal`/`emotional`/`athlete`/`retire`/`nervous` 等才是真该换的词。

> 对 A2/B1/B2 几乎无影响 —— 它们的超纲词本就在本档范文基线之外。
> 这处修正实际只对 `A1-` 起作用，而 `A1-` 恰好是最需要它的一档。

### 上线后的实测规避词（真实素材，4 档）

| 素材 | A1- | A2 | B1 | B2+ |
|---|---|---|---|---|
| NPR 体育 | 11 词 | 18 词 | 12 词 | 10 词 |
| CGTN 商业 | 19 词 | 20 词 | 20 词 | 20 词 |
| 科学类 | 20 词 | 20 词 | 20 词 | 20 词 |

（上限 20 词/档。`B1` NPR 那篇未超标，不参与回灌。）
