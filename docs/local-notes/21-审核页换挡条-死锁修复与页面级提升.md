# 21 · 审核页换挡条：死锁修复 + 提到页面级

> 需求原话（Bryan）：
> 「文章审核过程中，也需要有换挡的切换按钮，就是 A1, A2, B1, B2+，
> 然后点击对应的按钮后，显示不同的文章段落，进行审核。」
>
> 结论：**这个按钮早就存在**，不需要新建。真问题有两个 —— 它藏在卡片里看不见；
> 切到无内容的大档后**它连同自己一起消失，用户被困住**。

改动文件：`frontend/index.html`（单文件）
提交：`e1d0ddcf` → 线上 678053 → 680133 字节

## 1. 现状实测（改之前）

审核页 `s12()` 早就在用 `alignedViewHTML()`，它内部调 `bigBarOnce()` 渲染 4 个大档 tab，
点了确实换挡（走 `setBig()`）。两个真问题：

### 1.1 藏得太深

切换条渲染在 `alignedViewHTML()` 内部 → 位置在「人工审核中」上下文条 → lede 段 →
素材原文卡 → **「逐段原文」卡片内部**。1440×900 首屏看不到，要往下滚约一屏。
用户第一眼会判定「审核页没有换挡按钮」。

### 1.2 切到空档 → 切换条跟着消失 → 死锁（P0）

`alignedViewHTML()` 开头有这行守卫：

```js
const has = lvls.some(k => GEN[k] && GEN[k].paras && GEN[k].paras.length);
if (!has) return "";      // ← 整块返回空，切换条就在这块里，一并消失
```

CDP 实测（文章只含 A1/A2 两档 —— 区间模型下短素材的常态）：

| 动作 | 当前大档 | `.bigbar` | `.bigtab` | `.pcard` |
|---|---|---|---|---|
| 进审核 | A2 | 1 | 4 | 15 |
| **点 B1** | B1 | **0** | **0** | 0（只剩「尚未有生成文章」） |
| 点 A1 | A1 | 1 | 4 | 12 |

第 3 行是靠 JS 强行 `setBig('A1')` 回去的 —— **真实用户点不到那个按钮，只能退出审核**。

⚠️ 这不是边缘 case：区间模型下「素材只到 A2.3、B1/B2+ 不适用」是设计预期，
审核页必然遇到。与「前端还没消费区间字段」是同一个根因。

同样的守卫在 `s9`（段落校对）、`s10`（人工校对）、`quizAlignedHTML` 里也有同族写法。

## 2. 改动（5 处，一个文件）

| # | 位置 | 改动 |
|---|---|---|
| 1 | CSS `.bigtab.sel b` 之后 | 新增 `.bt-n`（内容数标识）/`.bt-n.off`/`.bigtab.blank` 样式 |
| 2 | `bigBarHTML()` 前 | 新增 `bigParaCount(big)` 助手 |
| 3 | `bigBarHTML()` | 每个 tab 追加内容标识；空档加 `blank` 虚线类 |

### 2.1 关键一行：为什么提页面级不会出两条

`_bigBarUsed` 是「一页只渲染一次」的闸门，`render()` 开头复位：

```js
function render(){ _bigBarUsed = false; ... }
function bigBarOnce(){ return _bigBarUsed ? "" : bigBarHTML(); }
```

`s12()` 里先 `const bigBar = bigBarOnce()` 占住闸门，`alignedViewHTML()` 内部那次
就会自动返回空串 —— **不可能出现两条切换条**，只是把唯一那一条挪到首屏。

### 2.2 空态文案分两种

`emptyGroupHTML()` 按「本篇是否存在任何内容」分流：

- 有内容但他档 → 「本大档（B1）本篇暂无生成内容 —— 该档位在本文的生成区间之外，
  请用上方大档按钮查看有内容的档位」
- 整篇都没生成 → 「尚未有生成文章，请先运行内容生成工作流」

### 2.3 tab 内容标识

| 状态 | 视觉 |
|---|---|
| 有内容 | 橙点 + 段数（`#D04418` 字 / `#FFF0EB` 底），如 `A2 初级 ●15` |
| 无内容 | 虚线边框 + tab 字母转灰 + 灰点 + `0`（`#98A2B3` / `#F2F4F7`） |

色相仍只在「黑/灰/品牌橙红」三系内（`#F2F4F7` `#98A2B3` 属冷调中性灰，已获准）。
