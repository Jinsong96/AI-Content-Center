A 档 · 必须修7 项

A1

窄屏横向溢出 137px，右侧内容被切

已修复A 档
现象420px 视口下整个页面被撑到 557px，要左右拖动才能看全；每页都一样。
证据document.documentElement.scrollWidth = 557，innerWidth = 420。 根因：#body{grid-template-columns:220px 1fr} 的 1fr 列默认 min-width:auto， 被内部内容顶到约 336px；而全站 9 条 @media 里没有一条处理 ≤700px 的骨架（只改了卡片网格）。
影响iPad 竖屏 / 分屏 / 手机打开时，右侧按钮（含"运行""存入文章库"）被裁在屏幕外。
建议≤820px 时把左侧栏改为抽屉（页面里已有 #drawer 组件可复用），主区加 min-width:0。
A2

「修改自动保存」名不符实：改完刷新就没了

已修复A 档
现象段落校对页写着"点击任意段落文字即可编辑，修改自动保存"，但刷新页面 / 关掉标签后改动全部消失，且全程没有任何保存提示。
证据paraEdit() 只写内存对象 GEN[k].paras[i]； 全站 localStorage 只存了 5 个键（api_base / taxonomy / 来源 / 素材库 / 文章库），不含草稿； beforeunload 出现 0 次。
影响老师改了十几段，误刷新一次全丢 —— 这是最伤信任的一类失败。
建议写入 localStorage 草稿并按素材 id 关联；退一步至少加 beforeunload 拦截提醒 + 状态栏"已保存到本轮"。
A3

长任务进度是"按预估时间算的假进度"，且不能取消

已修复A 档
现象内容生成进度条走到 100% 后停住不动，几十秒毫无反应，看起来像卡死。
证据GEN_EST = 90（源码注释按 ~77s 留余量），而 Dify GEN 实测 110–180s； 进度 = elapsed / GEN_EST，只跟挂钟走，与真实节点无关。 真实节点计数 nodeDone 已经拿到了，却只用在 chip 小字里。同时无 AbortController、无「取消」入口。
影响老师以为卡死 → 刷新页面 → 触发 A2 的丢数据。
建议进度改用 node_finished 节点数（如"12/21 节点"）；到预估时间后改为"仍在生成，已用 132s"而不是顶在 100%；补「取消本次生成」。
A4

0 条数据时，界面同时显示"统计卡 0 / 暂无匹配 / 分页 1-1"

已修复A 档
现象素材库、文章库空空如也时：4–5 张统计卡全 0，中间一句灰字"暂无匹配素材"，下面还有一套分页控件「首页 ‹ 第 1/1 › 末页」。
证据截图 audit-empty 可复现；空态文案 empty-state 与分页、统计卡是三个独立渲染块，没有"总数为 0"的统一分支。
影响看着像坏了；新老师不知道下一步该干什么。
建议总数为 0 时切换成引导型空态："还没有素材 → 去热点搜集 / 粘贴自有原文"，并隐藏分页与统计卡。
A5

没选素材时，「运行抽取」按钮依然可点

已修复A 档
现象「06 事实抽取」页左侧"原文"栏是空的，右侧橙红色实心按钮「运行抽取 Workflow · E1–E9」却是可点状态。
证据源码里算了 const ready = ...，但按钮分支只有 <button class="btn" onclick="extract()">，没有用 ready 去禁用。
影响点下去报的是"抽取失败"类错误，而真实原因是没选素材 —— 报错与原因不符，用户会以为系统坏了。
建议无素材时按钮 disabled + 灰字"请先在 01 选择素材"，旁边给一个直达 01 的链接。
A6

段落下的「引用事实卡 F1」看不到事实内容

已修复A 档
现象每个段落卡片底部有 引用事实卡 F1 F3 的标记，但悬停、点击都没有反应，看不到这三条事实具体是什么。
证据factCiteHTML() 输出的是裸 <span>F1</span>，无 title、无点击事件； 事实卡正文渲染在另一个页面（事实抽取页 / 侧栏）。全站 aria-* 计数为 0。
影响校对老师无法就地判断"这段有没有偏离事实"——溯源这个卖点在界面上等于没兑现。
建议悬停/点击就地展开该事实卡的中英原文；文案改成"事实卡 1"而不是 F1。
A7

内部代号直接暴露给老师

已修复A 档
现象界面上出现 「运行抽取 Workflow · E1–E9」「F1 F2」「KB1–KB7」「V1-V13」「FC-1」等代号。
证据分别来自 <div class="matflow-h">、factCiteHTML、s5() 知识库卡、STAGES[8].s、"AI 校验"页。
影响教研老师不知道 E1–E9 指什么，会以为是操作说明的一部分。
建议代号统一收进 hover 提示或"技术细节"折叠区；正文只留业务语言（如"运行事实抽取"）。

B 档 · 建议修10 项

B1

说明性文字对比度只有 2.5，全站每页 30–40 处不达标

已修复B 档
现象"字太浅看不清" —— 页面副标题、工作流标题、用户名、空态文案、顶栏 Demo 徽标，全是浅灰小字。
证据实测 #98A2B3 在 #FFFDF9 上 2.53:1、白底 2.58:1，字号 10–13px（WCAG AA 正文线 4.5:1）。 受影响选择器：.sub .matflow-h .badge .empty-state .uinfo span .wfstrip-h。
建议说明文字换 #667085（4.6:1）级；10–11px 一律提到 12px。
B2

品牌橙当正文色，对比度 3.3–3.7；#F79009 作数字只有 2.25

已修复B 档
证据侧边栏当前项（14px）#E65425 on #FFF0EB = 3.34；卡片脚注 11px 橙字 3.71； 工作流步骤序号 #F79009 on #FFF9F5 = 2.25（16px 数字，几乎糊在底色里）。
建议文字层用深一档的 #C2421C；#E65425 / #F79009 只留给色块、描边、图标。这不破坏现有的"黑/灰/橙红"配色纪律。
B3

三套导航并存，且底部那套「12 步」点不动

已修复B 档
现象左侧栏 4 项 + 页内"素材创建/文章生产 · 工作流"步骤条 + 每页底部一大块「完整工作流 · 12 步（当前高亮）」。底部这套看起来最像导航，实际点了没有任何反应。
证据artWorkflowBar() 的节点带 onclick="go(idx)"；wfStrip() 的 12 个 .wfnode 无任何事件属性。 另：侧边栏按品牌规范已去掉数字编号，这里却出现 01–12，风格自相矛盾。
建议两条路选一：把它改成可点缩略导航（复用 go()），或去掉编号降级为进度指示条，且只在顶层页显示。
B4

一个页面里两排几乎一样的档位切换条

已修复B 档
现象内容生成 / 段落校对 / 逐段审核页，上面一排「A1 入门 · 7　A2 初级 · 7　B1 中级 · 7　B2 中高级 · 7」，紧跟着下面又一排「A1 A2 B1 B2」。
证据分别是 .plvlbar（纯展示）和 bigBarHTML()（真切换）。两者外观都是 pill，看不出哪个能点。
建议合并成一组：可切换的 pill，选中态显示段数（如"B1 中级 · 7 段"）。
B5

四栏对照每栏约 180px，一行只放 3–5 个单词

已修复B 档
现象1440px 下段落校对四栏并排，A1 档一段被折成 4 行、每行三四个词，读起来眼睛来回跳。
证据截图 audit-align-1440；.alignrow{grid-template-columns:44px 1fr 1fr 1fr 1fr;gap:10px}，主区可用宽度约 900px → 每栏 ≈180px。
建议给一组「对照视图 / 单档视图」开关；单档时整幅宽度显示，适合逐字校对。同时 @media ≤900px 目前直接塌成一列，等于把四栏对照的优势丢了。
B6

校对页把浏览器拼写检查关掉了

已修复B 档

建议改成 spellcheck="true"（如需干净截图，加一个开关）。英语校对场景下红波浪线是刚需，不是噪音。
B7

登录页三张角色卡：信息量差一倍、术语看不懂、没有主次

已修复B 档
现象"市场老师"卡只有 5 个标签，"教研老师 / 审核老师"有 9 个，卡片等高 → 市场老师卡下半部大片空白； 标签是步骤名（素材选择 / 敏感排除 / 逐段审核），新老师看不出这个角色能做什么；三个"登录"按钮长得一模一样、都是主按钮。
证据截图 audit-login；.lrole{min-height:280px} 强制等高 + @media≤820px 才塌成两列。

B8

「退出」没有二次确认，一点就清空会话

已修复B 档
证据顶栏退出按钮 onclick="logout()"，logout() 内无 confirm；退出后生成结果与未入库文章都在内存里，直接消失。
建议有未入库产出 / 任务运行中时，二次确认并提示"当前生成结果尚未存入文章库"。
B9

抽屉和弹窗不能按 Esc 关闭，全站无键盘通道

已修复B 档
证据实测：打开素材详情抽屉后派发 Escape，抽屉保持 open。 全站仅 1 处 onkeydown（自由标签输入的回车提交），aria-* 计数 0。
建议补 Esc 关闭抽屉 / 弹窗；输入框统一支持回车提交（登录页、添加来源）。
B10

切到 EN 后，主题分类与写作风格仍是中文

已修复B 档

建议给 TOPIC_CATS / STYLES 补 en 字段，并加一条"EN 模式无残留中文（内容除外）"的回归检查。
